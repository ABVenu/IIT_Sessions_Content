title: Python Foundations and Version Control

objective: Revise the shared Python core — from the environment through classes — and the Git workflow used to save, share, and review that work.

type of session: theory

topics be covered: Environment and tooling; variables, types, and operators; conditionals and input; loops; lists, strings, and dictionaries; functions; classes; Git and GitHub


detailed subtopics to be covered:

* Set up and run Python safely: PATH, terminal, virtual environments, scripts versus notebooks, and where secrets belong.
* Revise variables, types, operator precedence, comparisons, and the bugs that come from mixing types or confusing assignment with equality.
* Revise conditionals, short-circuit logic, input and output, and f-strings.
* Revise while and for loops, range, break, continue, and nested loops, including the ways loops fail to stop.
* Revise lists, strings, dictionaries, functions, and classes, with the edge cases that change what the program actually does.
* Revise Git’s three areas, the everyday commands, branches, pull requests, and how to undo work without losing the history that matters.
