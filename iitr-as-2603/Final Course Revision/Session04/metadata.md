Target Audience : Students from any backgorund may not be necessarily form tech background

Session Notes Length: 500 lines to 700 lines

title: Tools, Safety, Orchestration, and Operations

objective: Revise how agents call tools and return structured results, how LangChain packages that loop, how workflows are controlled and made safe, and how a system is evaluated, observed, deployed, and costed.

type of session: theory

topics be covered: HTTP and JSON; tool calling; LangChain chains, tools, and memory; MCP; structured outputs; safety and guardrails; graph workflows; evaluation, deployment, and cost


detailed subtopics to be covered:

* Revise HTTP methods, status codes, and JSON as the contract between an agent and the outside world.
* Revise the tool-calling loop, tool schemas, and why a shared tool protocol reduces one-off integrations.
* Revise LangChain as composable parts: prompt templates, a chain, tool binding, an agent loop with a step limit, and session memory kept beside that loop.
* Revise structured outputs, parse-then-validate, prompt injection, and input versus output guardrails.
* Revise graph workflows: nodes, edges, shared state, checkpoints, timeouts, retries, and human approval gates.
* Revise traces, golden checks, release gates, secrets, hosting shape, caching, rate limits, and cost decisions.
