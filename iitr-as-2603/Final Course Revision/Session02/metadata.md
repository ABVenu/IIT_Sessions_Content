Course Name: Certification in Agentic Systems and Design / Software Engineering with AI / Software Development with Applied AI

Target Audience : Students from any backgorund may not be necessarily form tech background


session duration: 1hr  50mins

Session Notes Length: 500 lines to 700 lines

title: Agents, Language Models, Prompts, and Memory

objective: Revise how an agent thinks and acts, how a language model actually behaves, how prompts steer that behavior, and how memory keeps a conversation coherent.

type of session: theory

topics be covered: Agent definition and loop; LLM behavior, tokens, and limits; prompt design; reflection and feedback; short-term and long-term memory


detailed subtopics to be covered:

* Define an agent as a goal-driven loop of observe, think, and act, and separate the model from the tools that carry out actions.
* Revise next-token generation, hallucinations, knowledge cutoffs, temperature, context windows, and local versus hosted models.
* Revise system, user, and assistant roles, zero-shot and few-shot prompting, chain-of-thought, prompt templates, and self-correction.
* Revise stateless versus stateful behavior, short-term and long-term memory, and buffer, window, and summary strategies.
* Revise the practical failure modes: runaway loops, context overflow, lost detail, and memory that is stored in the wrong place.
