title: Masterclass: Evolution of the Web

objective: How the web evolved, how browsers render pages and run JavaScript, and how frontend, server, and backend split the work

type of session: theory

topics be covered: Need for web evolution; limits of static Web 1.0; Web 2.0 interactivity; browser rendering; JavaScript in the browser; frontend vs server vs backend; role of backend; APIs and cloud shift; Web 3.0 at a high level


detailed subtopics to be covered:
* Explain why the web needed to evolve beyond static Web 1.0 pages
* Explain the demerit of static-only websites for modern user interaction and products
* Explain how Web 2.0 changed websites into interactive user-driven platforms
* Explain how a browser loads and renders a web page for the user
* Explain the role of JavaScript runtime inside the browser for dynamic web behaviour
* Explain what a server is and how it differs from frontend
* Explain the role of backend in a web product (shared data, rules, secrets)
* Contrast frontend (HTML/CSS/JS in the browser) with backend (a listening server program)
