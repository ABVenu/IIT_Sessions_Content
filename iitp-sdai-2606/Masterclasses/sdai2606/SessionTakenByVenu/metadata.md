title: Hands-On: Building a Complete Frontend Application

objective: Map how frontend, backend, database, and API share one web product, and build a Todo app that saves tasks in the browser with Local Storage, including how JavaScript runs work through the event loop.

type of session: mixture of theory + implementation

topics be covered: Web flow (frontend, backend, database, API); HTTP methods and status codes; Elements of frontend engineering; Elements of backend engineering; JavaScript single-threaded behaviour; Event loop; Todo application with Local Storage


detailed subtopics to be covered:
* Explain how a typical web product moves a request across frontend, API, backend, and database
* List the working elements of frontend engineering (structure, style, behaviour, state, events, DOM updates, client storage)
* List the working elements of backend engineering (server, routes, validation, rules, database, auth, JSON response) and where today’s app stops
* Explain typical JavaScript behaviour: top to bottom, functions run only when called, one call stack
* Explain the event loop with call stack, browser Web APIs, callback queue, and a zero-delay timer
* Build one complete Todo page that adds, completes, and deletes tasks and reloads them from Local Storage
